# EY21 on firmware 5.6.1.1

Verified target:

- Model: EY21, Kindle Paperwhite 1 (2012)
- Serial prefix: B024 (Wi-Fi variant; the complete serial is not stored)
- Firmware: 5.6.1.1, build 2689890035
- Display: 758×1024, 16-level grayscale
- Kindle software family: legacy/soft-float

The `B024` value is a shared model-family prefix, not a unique device serial.
It is included only to select the correct compatibility profile. Never put a
complete Kindle serial number in this repository or its configuration files.

## Start without jailbreaking

Store registration is unrelated to local HTTP. Before modifying the device:

1. Start the dashboard server on the computer.
2. Connect the Kindle and computer to the same Wi-Fi.
3. In the Kindle Experimental Browser, open
   `http://COMPUTER_LAN_IP:8787/kindle`.
4. If the dashboard appears, bookmark it. This is the lowest-risk deployment.

The page intentionally uses plain HTTP, one PNG, no JavaScript, and an HTML
refresh directive to suit the old WebKit browser and TLS stack.

## Exact jailbreak route

The B024 prefix identifies the Wi-Fi Paperwhite 1. The current
[KindleModding jailbreak data](https://github.com/KindleModding/kindlemodding.github.io/blob/main/static/jailbreaks.json)
lists **WinterBreak2** for Paperwhite 1 on firmware 5.6.1.1. That entry does not
require an Amazon registration or lock-screen advertisements. Confirm the
selection in the live [jailbreak wizard](https://kindlemodding.org/jailbreak-wizard.html)
before proceeding because its compatibility data can change.

Use the current [official WinterBreak2 guide](https://kindlemodding.org/jailbreaking/WinterBreak2/),
not an old downgrade package or a `.bin` selected from a forum attachment:

1. Charge the Kindle, back up all USB-visible storage, and keep it on external
   power during the procedure.
2. Download the latest `wb2.zip` from the guide and extract its contents to the
   root of the Kindle USB drive. Confirm that a `winterbreak2` folder exists at
   the root before ejecting it cleanly.
3. Connect the Kindle to Wi-Fi, open Experimental Browser, and visit
   `https://penguins184.xyz/wb2` exactly as directed by the guide.
4. Press **Jailbreak** once and wait without rebooting or disconnecting power.
5. Complete the guide's **What's Next** steps. Remove its temporary filler and
   `.bin` files only when the guide tells you to.

If the page fails to load, reboot and retry after checking Wi-Fi. If the button
does nothing, re-check that `winterbreak2` is at the USB root and reboot. The
official guide names original WinterBreak as a fallback on firmware below
5.16.4, but that fallback requires registration. Stop and consult the guide's
support channel if WinterBreak2 still fails; do not improvise a firmware
downgrade.

## Install the dashboard after jailbreak and hotfix

Hotfix 2.5.0 supplies `sh_integration`, so this deployment uses document
scriptlets and does not require KUAL. The dashboard runtime is at:

```text
kindle/ey21-5.6.1.1/extensions/kindle-dashboard
```

1. Edit `dashboard.conf` and put the computer's LAN address in `DASHBOARD_URL`.
   On this firmware, use standard HTTP port 80; the Experimental Browser and
   device client failed to reach the same server on port 8787.
2. Copy the `extensions` folder to the root of the Kindle's USB storage,
   merging it with the existing folder.
3. Copy the two `.sh` files from this package's `documents` directory into the
   Kindle's `documents` directory.
4. From the Kindle library, open **Start Kindle Dashboard**. Open **Stop Kindle
   Dashboard** to return to normal operation.

The extension prevents sleep, waits for the launcher to finish repainting, downloads a
fresh PNG every 60 seconds, and displays it with the firmware's `eips` utility.
The stop scriptlet restores normal sleep behavior.

Diagnostics are written to `/mnt/us/kindle-dashboard.log`, which is visible over
USB. A failed fetch also shows the `wget` exit code on screen.
